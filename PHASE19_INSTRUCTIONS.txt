PHASE 19 — URL REDIRECT MANAGEMENT CMS (INCREMENTAL / SAFE)

Goal
----
Add database-backed management for public URL redirects without changing any current public URL.
No redirects are seeded.

Install
-------
1. Import database/phase19_redirects.sql into the existing State Corps database.
2. Copy app/core/Redirect.php and RedirectManager.php into publicV6/app/core/.
3. Add to publicV6/app/bootstrap.php:
   require_once __DIR__ . '/core/Redirect.php';
   require_once __DIR__ . '/core/RedirectManager.php';
4. Add scadmin/redirects/ to the project.
5. Give the Administrator manage_redirects if the permission UI does not automatically grant new permissions.

Public runtime integration
--------------------------
Add this line near the TOP of publicV6/app/public_bootstrap.php, after app/bootstrap.php is loaded and BEFORE any public output:
   Redirect::applyCurrentRequest();

This is intentionally not hard-wired by the package because the existing public_bootstrap.php source was not included in the uploaded project structure.
With zero rows in url_redirects, this line has no effect.

Admin
-----
Open /scadmin/redirects/
Create a source path such as /old-page and a local destination such as /new-page, or an http/https destination.
Supported status codes: 301, 302, 307, 308.
Query preservation is optional.

Safety
------
- Admin routes require manage_redirects.
- Save/toggle/delete require CSRF and POST for state changes.
- Admin/application paths cannot be configured as sources.
- javascript:, data:, whitespace, and malformed destinations are rejected.
- Source paths are unique.
- Existing public URLs remain unchanged until a redirect is explicitly added and enabled.
- No public login, public HTML/CSS/JS, or existing content is overwritten.

Permissions
-----------
The SQL creates manage_redirects only. Existing editor grants are not automatically changed.

Rollback
--------
Remove the two Redirect require_once lines and the scadmin/redirects folder. The table and permission can remain unused or be removed manually after backup.
