# Admin CSS phases

This folder groups admin styles by phase and concern so they are easier to maintain.

## Phase 2 - admin UI
- admin-core.css
- admin-homepage.css
- admin-about.css
- admin-sectors.css
- admin-services.css
- admin-media.css
- admin-legal.css

The main wrapper file, `scadmin/assets/css/admin.css`, imports these grouped files so existing admin pages keep working while the structure is cleaned up.
