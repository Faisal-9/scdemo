PHASE 28 — CENTRAL MEDIA LIBRARY + VISUAL MEDIA PICKER

This phase consolidates asset management around one central database-backed library and adds a reusable visual picker for admin forms.

Primary URL:
/scadmin/assets-library/

Key capability:
Type an asset name into the picker, see matching thumbnails/files from the database, click one, and have the selected relative path linked into the form.

Existing site images/documents can be registered without moving them.
