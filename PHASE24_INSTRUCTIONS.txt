STATE CORPS ENGINEERING CMS — PHASE 24
SYSTEM HEALTH / CMS CHECKUP CENTER

PURPOSE
Add a read-only diagnostic screen for administrators/editors who are explicitly
allowed to view it. It checks the PHP runtime, required extensions, database
connectivity, core CMS tables, required directories, upload limits, PHP sessions,
and recommended response security headers.

INSTALLATION
1. Back up the project and database.
2. Extract this package into the existing publicV6 project root.
3. Import database/phase24_system_health.sql into statecorps_db.
4. Grant the new manage_system_health permission only to the account(s) that
   should see system diagnostics.
5. Visit /scadmin/system-health/index.php.
6. Add one sidebar/dashboard link to that URL if desired.

SAFETY
- No public frontend files are changed.
- No CMS content is edited.
- No database records are deleted or rewritten.
- No automatic repairs are performed.
- The screen intentionally does not display database credentials or raw exception messages.

CHECKS
- PHP version/runtime
- Required PHP extensions
- Database connection and server version
- Expected CMS database tables
- Core CMS directories and upload writability
- upload_max_filesize and post_max_size against the CMS 15M PDF limit
- PHP session availability
- Recommended security headers in the current response

HOSTING NOTE
A warning on local XAMPP (such as missing security headers) can be normal.
Review warnings again after deployment to cPanel/production.
